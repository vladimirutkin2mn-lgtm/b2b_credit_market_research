# Starting-Point Playbooks by Lender Archetype

**Version:** 2026-10-02  
**Purpose:** adjust the generic roadmap to the institution's structural starting point.

These are **scenario playbooks**, not rankings.

---

# Archetype 1 — Transaction-rich incumbent bank

## Starting assets
- SME current accounts;
- long transaction history;
- deposits;
- existing KYB;
- RM network.

## Typical weakness
Data exist but are not converted into:
- continuous eligibility;
- dynamic limits;
- fast credit lanes.

## Default priorities

1. Existing-customer pre-underwriting.
2. Reuse KYB/customer data.
3. Explicit automation perimeter.
4. Dynamic repeat/top-up.
5. Relationship workflow redesign.

## Do not start with
- generic new-to-bank fintech clone;
- separate digital lender that ignores incumbent data.

## Evidence analogs
CommBank, SBI, Rabobank, Itaú.

---

# Archetype 2 — Relationship-heavy SME bank

## Starting assets
- skilled bankers;
- deep customer knowledge;
- larger tickets;
- pricing power / relationships.

## Typical weakness
- too many handoffs;
- manual data gathering;
- opaque process;
- weak productivity metrics.

## Default priorities

1. Digital credit pack.
2. Data prefill / spreading.
3. Named case owner.
4. Delegated authority.
5. Conditions / legal orchestration.
6. RAROC by relationship lane.

## Do not start with
- removing underwriters;
- forcing large-ticket STP.

## Evidence analogs
Judo, Allica, Commerzbank.

---

# Archetype 3 — Payments / acquiring platform

## Starting assets
- merchant sales;
- frequency;
- refunds/chargebacks;
- embedded merchant surface;
- repayment control.

## Typical weakness
- credit-risk/vintage discipline can lag growth;
- funding/capital may constrain scale.

## Default priorities

1. Continuous merchant eligibility.
2. Bounded pre-approved offers.
3. Sales-linked repayment.
4. Vintage/limit governance.
5. Repeat dynamic limit.
6. asset distribution / funding optimization if appropriate.

## Do not start with
- broad manual SME credit outside observed merchant perimeter.

## Evidence analogs
Stone, Square, Mercado Pago.

---

# Archetype 4 — Digital non-bank SME lender

## Starting assets
- digital acquisition;
- automated underwriting;
- fast product iteration.

## Typical weakness
- higher funding cost;
- acquisition cost;
- limited relationship data;
- balance-sheet constraints.

## Default priorities

1. Machine-readable data depth.
2. Repeat/reuse.
3. partner/accounting/payment distribution.
4. funding diversification / asset distribution.
5. product-engine economics.

## Do not start with
- expanding tickets faster than evidence/risk/funding support.

## Evidence analogs
Funding Circle, iwoca, Floryn, Konfío, UGRO.

---

# Archetype 5 — Universal bank with guarantee-program scale

## Starting assets
- balance sheet;
- distribution;
- government program access;
- tax/revenue integrations.

## Typical weakness
Guarantee products can remain operationally separate/manual.

## Default priorities

1. Digitize program eligibility.
2. Integrate bank and government data.
3. separate guaranteed economics.
4. measure incremental approval.
5. automate claims evidence.

## Evidence analogs
Itaú, SBI, Stone.

---

# Archetype 6 — Specialist receivables / asset financier

## Starting assets
- specialist underwriting;
- collections;
- collateral/debtor knowledge.

## Typical weakness
- manual asset ingestion;
- fragmented portal;
- expensive recurring operations.

## Default priorities

1. invoice/asset ingestion.
2. automated availability.
3. debtor/collateral monitoring.
4. self-service drawdown.
5. funding matching.
6. fraud analytics.

## Evidence analog
Bibby / specialist asset-finance units.

---

# Strategic use

The same capability can have different value by archetype.

Example:

**Open Banking**
- high value for digital new-to-bank lender;
- incremental value for a bank already holding primary transactions;
- lower relevance for pure receivables finance where invoice/debtor data dominate.

Therefore the roadmap should start from **structural assets and constraints**, not industry fashion.
