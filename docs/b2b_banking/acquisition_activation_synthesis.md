# Привлечение, активация и удержание внешнего бизнеса

## Вывод

Внешняя компания может начать отношения с конкретной финансовой задачи, отраслевого сервиса или кредита, сохраняя другой основной банк. В выборке это документировано как доступный маршрут, но преимущество по стоимости привлечения и удержанию не установлено. Направление поиска для Ozon Банка — полезная первая операция и доступные данные; размер открытой базы сам по себе не определяет кредитный результат. Статус: аналитический вывод по публичным продуктам / Medium; ожидаемый эффект для банка — гипотеза / Low.

## Полезная активация

Предлагаемое определение: выполненная внешняя операция, которая решает задачу бизнеса. Пополнение между своими счетами и получение выданного кредита сами по себе не подтверждают полезность РКО. Для каждого сегмента заранее выбрать событие: оплата реального поставщика, поступление от покупателя, выполненная зарплатная ведомость либо завершённая и проверенная сверка. Не объединять эти события в один показатель без разрезов.

Для платёжной платформы первой полезной операцией может быть обработанная продажа; для кредитного входа — выдача на подтверждённую потребность. Поэтому сравнение начинается с исходного клиента, а не с одинакового названия «счёт». У кредитного входа после выдачи отдельно измеряется самостоятельное использование платежей.

## Частичная миграция и помощь

Документированные способы уменьшить нагрузку: импорт банковской истории, счетов и справочников; доступ бухгалтера; роли согласующих; связь с учётом; оплата из внешнего источника. Они позволяют перенести часть работы. Данных для причинного вывода «помощь увеличила удержание» нет. Allica требует основной счёт для овердрафта; это условие продукта, а не наблюдение о реальном переносе оборотов. BB-C0070/0071/0081; BB-C0158/0160; BB-C0390/0391/0392.

Миграцию измерять по новым независимым контрагентам, повторным операциям и доле подтверждённого внешнего оборота при полном знаменателе. Если общий оборот неизвестен, показатель назвать объёмом наблюдаемых операций, а не долей кошелька клиента. Сотруднику поддержки считать время внедрения и число неуспешных попыток подключения.

## Удержание и кредитная пригодность

Регулярные задачи дают повод возвращаться, но нельзя превращать продуктовую частоту в доказанное удержание. Доля выручки Funding Circle от старых когорт не равна вероятности сохранения клиента. Само подключение внешнего банка не доказывает полноту финансовой картины. Отсутствие операций может быть сезонностью, сменой банка или прекращением бизнеса; причины различать.

Предлагаемая воронка: приглашён → подключён → выполнил полезную операцию → повторил задачу → имеет достаточно качественных данных → подходит под риск-политику → получил предложение → получил деньги → погасил → получил экономический результат. Единица — уникальный бизнес в когорте подключения; кредитные события учитываются отдельно. Для каждого перехода нужен согласованный период и исходный знаменатель. Перемножение процентов разных компаний недопустимо.

## Как проверить преимущество

Сравнить одинаковые сегменты и каналы по маршрутам «счёт», «задача», «кредит». Где возможно — случайное распределение приглашений; в иных случаях заранее задать сопоставимые группы и описать остаточный отбор. Первичный показатель — стоимость компании с полезной повторной активностью; следующий — стоимость пригодного заёмщика и прибыль зрелой когорты. Обращения, открытые счета и кредитные предложения оставить диагностическими показателями.

Сильное альтернативное объяснение зарубежного успеха — исходно качественные клиенты и уже существующая дистрибуция. Оно не отвергнуто публичными данными. Решение о масштабировании требует внутренних наблюдений, а не популярности бренда.
