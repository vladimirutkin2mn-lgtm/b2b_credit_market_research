## Термины и единицы

Официальные названия продуктов сохранены. Сокращения ниже не отменяют отдельные определения каждого источника.

| Термин | Значение в отчёте |
| --- | --- |
| РКО | Расчётно-кассовое обслуживание; открытие счёта и фактическое использование различаются |
| P&L | Отчёт о доходах, расходах и финансовом результате |
| PBT | Прибыль до налога; не экономическая прибыль после платы за капитал |
| FTP | Согласованная внутренняя трансфертная стоимость фондирования |
| ECL | Ожидаемые кредитные потери; запас резерва на дату не равен годовому расходу |
| NPL | Проблемные кредиты по определению источника; дни и знаменатель уточняются |
| EMI | Организация электронных денег; её платёжный счёт не банковский депозит |
| BRA | Business Rewards Account - бизнес-счёт Allica |
| AP-only | Режим оплаты счетов поставщиков без корпоративной карты Ramp |
| GGS / ENABLE | Британские гарантийные механизмы; предел зависит от программы и договора |
| FD-secured | Продукт, обеспеченный срочным депозитом; не обычный необеспеченный кредит |
| FY / Q / H1 | Финансовый год / квартал / первое полугодие; календарь источника уточняется |
| Годовой уровень выручки | Текущая выручка в пересчёте на год; не фактическая выручка полного года |
| Дополнительный эффект | Отличие результата теста от того, что произошло бы без нового предложения |
| Счёт / счёт на оплату | Банковский счёт и документ для оплаты не являются одним понятием |
