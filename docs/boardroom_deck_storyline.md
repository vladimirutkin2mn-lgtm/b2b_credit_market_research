# Boardroom Deck Storyline — SME / B2B Lending

**Version:** 2026-10-02  
**Format:** 21-slide boardroom presentation (19 core + 2 appendix)  
**Purpose:** executive synthesis of the completed public market-research cycle.

## Core storyline

1. **Cover — SME / B2B Lending: what actually creates advantage**  
   8 markets • 43-player universe • 18 deep dives.

2. **Executive summary — the winner is not the “most digital” lender**  
   Winning SME models align segment, data, decisioning, funding/capital and journey.

3. **Evidence base — broad enough for pattern recognition, deep enough for mechanisms**  
   8 markets, 43 players, 18 teardowns, 5 normalized journey archetypes.

4. **SME lending is several businesses, not one product**  
   Seven materially different operating models require different factories.

5. **Winning model = fit across five elements**  
   Risk object × observable data × decision model × funding/capital × customer journey.

6. **The fastest journey starts before the customer applies**  
   Existing-customer pre-underwriting converts application into offer configuration.

7. **Data substitution matters more than prettier forms**  
   Open Banking, tax/e-invoice, acquiring and relationship data replace manual documents.

8. **“Instant” lending has explicit boundaries**  
   Breakpoints at iwoca, Allica, Commerzbank, Floryn and Rabobank show that speed is segmentation.

9. **Human underwriting can be a competitive advantage**  
   In larger SME, automate administration and reduce handoffs rather than remove judgment.

10. **Better data does not guarantee lower losses**  
    Stone illustrates that embedded transaction data can coexist with weak vintages / high cost of risk.

11. **Funding is part of product design**  
    Deposits, originate-and-distribute, securitisation and wholesale models can all work with different constraints.

12. **High borrower yield is not attractive economics by itself**  
    Yield must be bridged through funding, credit loss, OPEX, capital and relationship value.

13. **Repeat lending can create a lifetime-value flywheel**  
    Repayment behavior → more data → dynamic limit → lower re-underwriting → faster repeat credit.

14. **Guarantees shift the approval / risk / capital frontier**  
    Digitized guarantee-backed lending should be a separate credit factory.

15. **Country infrastructure determines transferability**  
    Open Banking, tax/e-invoice, digital ID and guarantee rails differ materially by market.

16. **Target architecture — one intelligence layer, multiple credit factories**  
    Shared KYB/data/decision/orchestration layer supporting five risk-specific factories.

17. **Transformation roadmap — start backstage, not with the UI**  
    Measure → pre-underwrite existing SMEs → data substitution → repeat loop → relationship lane → specialist economics.

18. **Five management decisions distinguish a mature SME lending system**  
    Separate factories, explicit automation perimeter, factory-level economics, repeat product, empowered human judgment.

19. **What remains to prove**  
    The remaining questions are causal bank-specific economics: cost-to-serve, repeat uplift, existing-vs-new loss, RAROC, guarantee economics.

## Appendix

20. **Methodology / quality controls**  
    Comparability, source hierarchy, triangulation, contradiction search, causality, confidence.

21. **Evidence book — 18 deep dives**  
    Brazil, US, UK, Germany, India, Netherlands, Australia and Mexico.

## Presentation design principles

- answer-first headlines;
- one management message per slide;
- evidence and mechanism on the same page;
- no synthetic “best bank” ranking;
- public data shown only within defensible comparison scope;
- source notes on every quantitative page;
- appendix carries methodology rather than interrupting the core story.
