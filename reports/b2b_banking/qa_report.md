- Учтены R01–R14: [карта исправлений](../../docs/b2b_banking/review_resolution.md).
- Сценарии отделены от каналов; кредитная и сервисная активация — от готовности данных. Экономика включает всю исходную когорту, распределение затрат и границы формулы.

## Воспроизведение

Установить ReportLab, Pillow, pdfplumber, pypdf и Poppler. Использовать исходники указанной доказательной ревизии. Запустить из корня репозитория:

```bash
python scripts/build_b2b_report.py --evidence-commit 4f91aa893d9332a8f922bf716ea0b0f785e22f8a --published-commit e710b1b8d824bb5ec18a6999911f0d13ebf1f72b
mkdir -p /tmp/b2b_report_qa
pdftoppm -r 100 -png reports/b2b_banking/b2b_banking_external_growth_ru.pdf /tmp/b2b_report_qa/page
python scripts/validate_b2b_report.py /tmp/b2b_report_qa
python scripts/validate_b2b_evidence.py
```

Повторная структурная проверка возвращает visual_review=pending: новый выпуск требует отдельного просмотра. Бинарный SHA может меняться при повторной сборке из-за метаданных PDF.
