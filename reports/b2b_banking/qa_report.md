## Воспроизведение

Установить ReportLab, Pillow, pdfplumber, pypdf и Poppler. Запустить из корня репозитория:

```bash
python scripts/build_b2b_report.py
mkdir -p /tmp/b2b_report_qa
pdftoppm -r 100 -png reports/b2b_banking/b2b_banking_external_growth_ru.pdf /tmp/b2b_report_qa/page
python scripts/validate_b2b_report.py /tmp/b2b_report_qa
python scripts/validate_b2b_evidence.py
```

Повторная структурная проверка возвращает visual_review=pending: новый выпуск требует отдельного просмотра. Бинарный SHA может меняться при повторной сборке из-за метаданных PDF.
